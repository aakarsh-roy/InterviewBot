# 🚀 Quick Start Guide

## Get Started in 3 Minutes!

### Step 1: Setup (1 minute)

```bash
# Install dependencies
pip install -r requirements.txt

# Create your .env file
copy .env.example .env
```

Edit `.env` and add your Google Gemini API key:
```
GOOGLE_API_KEY=your_actual_api_key_here
```

Get your free API key: https://makersuite.google.com/app/apikey

### Step 2: Run (30 seconds)

```bash
python app.py
```

Open http://localhost:5000 in your browser

### Step 3: Practice! (90 seconds)

1. **Select preferences**: Tech stack, difficulty, question type
2. **Click "Start Interview"**
3. **Answer the question**
4. **Get instant AI feedback**
5. **Click "Next Question"** to continue

## 🎯 Pro Tips

### First Time User?
- Start with "Easy" difficulty
- Try "Technical Knowledge" questions first
- Use hints if stuck - they're there to help!

### Serious Practice?
- Do 5-10 questions in one session
- Track your average score
- Let the system adjust difficulty for you

### Preparing for Real Interview?
- Practice all question types
- Time yourself (aim for 5-10 min per question)
- Focus on "System Design" for senior roles

## 🔥 Power Features

### Get Hints
Stuck on a question? Click "Need Hint" for guidance without spoilers.

### Adaptive Difficulty
System automatically suggests harder/easier questions based on your score.

### Session Tracking
Your progress is tracked throughout the session - see improvement in real-time!

### Next Question
Click "Next Question" after feedback to continue with optimal difficulty.

Works perfectly on mobile browsers! Practice anywhere, anytime.

## ⚡ Keyboard Shortcuts

- `Tab` to navigate between fields
- `Enter` to submit forms (when focused)
- `Ctrl+A` to select all text in answer box

## 🆘 Troubleshooting

### "API Key Error"?
- Check your .env file has the correct key
- Make sure the key starts with "AI..."
- No quotes around the key

### Questions not loading?
- Check your internet connection
- Verify API key is valid
- Check console for errors (F12)

### Want to reset everything?
Click "Reset Session" button on the main page.
